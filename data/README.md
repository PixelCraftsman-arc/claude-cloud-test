# Word data

`words.js` is generated by `scripts/build-wordlist.mjs`. Don't edit it by hand.

It combines two sources:

- **Which words are valid:** SCOWL (Spell Checker Oriented Word Lists), as
  packaged in Debian's `wamerican` (size 50, American English).

  SCOWL copyright notice.
- **How common each word is:** the English 50k list from
  [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
  (`content/2018/en/en_50k.txt`), built from OpenSubtitles and licensed
  CC-BY-SA-4.0. Only the ordering of words is used.

## Regenerating

```sh
apt-get download wamerican && dpkg-deb -x wamerican_*.deb /tmp/wamerican
curl -sSLO https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/en/en_50k.txt
npm run build:words -- /tmp/wamerican/usr/share/dict/american-english en_50k.txt
```
